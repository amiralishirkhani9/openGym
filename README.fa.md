## این نسخه چه تفاوتی با نسخهٔ اصلی دارد؟

نسخهٔ اصلی [DuarteSantos8/openGym](https://github.com/DuarteSantos8/openGym) به‌صورت **self-hosted** با سرور Node و Passkey طراحی شده است. این فورک (`offline-fa`) کل لایهٔ سرور و حساب کاربری را حذف کرده و آن را به یک **اپ اندروید کاملاً مستقل، آفلاین و بومی‌سازی‌شده برای کاربران فارسی‌زبان** تبدیل می‌کند.

| قابلیت | نسخهٔ اصلی | نسخهٔ فارسی آفلاین (`v4`) |
|---|---|---|
| حساب کاربری و سرور | نیازمند سرور و Passkey | **حذف کامل** — تمام داده‌ها روی گوشی شما |
| مدیای ۱۳۲۴ حرکت | دانلود از CDN در زمان اجرا | **داخل APK با بازسازی AI (720×720)** |
| زبان و راست‌به‌چپ (RTL) | رابط انگلیسی، بدون فارسی | **فارسی کامل + RTL + فونت Vazirmatn** |
| نام و آموزش حرکات | فقط انگلیسی | **ترجمه فارسی هر ۱۳۲۴ حرکت + مراحل انجام آفلاین** |
| تقویم | میلادی | **تقویم شمسی (با امکان تغییر به میلادی)** |
| ست و وزن حرکات | الگوی ثابت برای اغلب حرکات | **تنظیم هوشمند بر اساس نوع حرکت** (وزنه، وزن بدن، کششی، ایزومتریک، کاردیو) |
| مربی هوشمند (AI Coach) | فقط از طریق سرور MCP | **داخلی و اختیاری** با کلید API دلخواه (OpenAI، Claude، Gemini، Ollama و...) |

## ویژگی‌های کلیدی

### ۱. مدیای باکیفیت و کاملاً آفلاین (720px AI Super-Resolution)
تمام **۲,۶۴۸ فایل** (۱,۳۲۴ انیمیشن MP4 + ۱,۳۲۴ تصویر ایستا WebP) داخل خود APK بسته‌بندی شده‌اند تا حتی در حالت هواپیما و بدون اینترنت اجرا شوند:
- **ارتقای هوشمند کیفیت (`tools/convert_gym_media_v4.py`):** تصاویر ایستا با مدل **Real-ESRGAN Anime 6B** و انیمیشن‌ها با **Real-ESRGAN x4v3** از ۱۸۰×۱۸۰ به **۷۲۰×۷۲۰** بازسازی شده‌اند (حذف کامل نقطه‌چین‌های GIF و جلوگیری از اعوجاج‌های `xBR`).
- **نمایشگر تمام‌صفحه و سازگار با تم تاریک:** امکان بازکردن تمام‌صفحه هر حرکت با یک لمس، کوچک‌کردن پلیر حین تمرین، و کاهش روشنایی مزاحم در محیط تاریک باشگاه.

### ۲. فارسی‌سازی ۱۰۰٪ بومی و تقویم شمسی
- ترجمه روان و اصطلاحی نام و آموزش مرحله‌به‌مرحلهٔ **تمام ۱,۳۲۴ حرکت** به‌صورت کاملاً آفلاین (`src/locales/ex/fa.js` و `src/instr/fa.js`).
- **جستجوی دو‌زبانه:** جستجوی هر حرکت هم با نام فارسی (مثل *پرس سینه*) و هم با نام انگلیسی (مثل *Bench Press*).
- **تقویم شمسی دقیق:** نمایش روزهای هفته، نوار خانه، نمودارها و تقویم ماهانه به **تاریخ شمسی** (در حالی که داده‌های خام به‌صورت استاندارد میلادی ذخیره می‌شوند تا بکاپ و آمار همواره دقیق بماند)، همراه با سوییچ تغییر بین شمسی و میلادی در تنظیمات.
- ترجمه کامل تمام بخش‌های بدن، تجهیزات، نام عضلات روی نقشه بدن، قوانین پیشرفت و جدول RIR/RPE.

### ۳. ست و وزن هوشمند متناسب با ماهیت حرکت
بسته به نوع حرکت، فیلدها و پیش‌فرض‌های مناسب به‌صورت خودکار انتخاب می‌شوند (و در هر لحظه حین تمرین با دکمهٔ تنظیمات حرکت قابل تغییرند):
- **حرکات با وزنه (هالتر، دمبل، دستگاه، سیم‌کش):** ست + تکرار + وزن + ردیابی پیشرفت خودکار (خطی، Greyskull LP، پیشرفت دوگانه).
- **وزن بدن و تجهیزات بدون وزنه (کش، فوم رولر، طناب، جیم‌بال، چرخ شکم):** مخفی‌شدن خودکار ستون وزن برای ثبت سریع‌تر، با دکمهٔ «افزودن وزنه» در صورت استفاده از کمربند وزنه.
- **دستگاه‌های کمکی (`Assisted`):** برچسب اختصاصی «وزن کمکی» به‌جای وزن بار.
- **حرکات کششی و موبیلیتی:** پیش‌فرض **۱ نوبت زمانی (۳۰ ثانیه)** بدون اجبار به چند ست و بدون ستون وزن.
- **حرکات ایزومتریک (پلانک، L-Sit و...):** شروع خودکار در حالت **تایمر ثانیه‌شمار** به‌جای شمارش تکرار.
- **کاردیو هوشمند:** تفکیک کاردیوی دستگاهی (مدت + سرعت) از کاردیوی بدون دستگاه مثل برپی و طناب‌زدن، همراه با امکان تغییر به حالت تکرار یا زمان.

### ۴. طراحی‌شده برای اندروید و محیط باشگاه
- **پشتیبانی از دکمهٔ Back اندروید:** بستن پنجره‌ها و بازگشت منطقی بین صفحات (`@capacitor/app`).
- **نوار دسترسی سریع بین حرکات:** پرش مستقیم به هر حرکت در تمرین فعال با نمایش وضعیت تکمیل هر حرکت.
- **تایمر استراحت و تایمر کار:** اعلان اتمام استراحت، ویبره، بوق و حفظ روشنایی صفحه در حین تمرین.
- **تحلیل پیشرفته:** نقشه خستگی و قدرت حفظ‌شده عضلات، هیت‌مپ فعالیت ۱۲ماهه، تخمین 1RM، ثبت RIR/RPE و نمودار وزن بدن با خط هدف.
- **مدیریت کامل داده:** خروجی و ورودی بک‌آپ JSON، اشتراک‌گذاری فایل برنامه، و واردکردن تاریخچه از Strong / Hevy / FitNotes.

## نصب روی اندروید

۱. به بخش **[Releases](https://github.com/amiralishirkhani9/openGym/releases/latest)** بروید و فایل **`openGym-4-fa.apk`** را دانلود و نصب کنید.
۲. اپ هیچ نیازی به ثبت‌نام، سرور یا کلید API ندارد (بخش مربی هوشمند کاملاً اختیاری است).

> **توجه هنگام ارتقا از نسخهٔ ۳ یا قبل‌تر:** اگر نسخهٔ قبلی روی گوشی نصب است، ابتدا از **تنظیمات ← داده‌ها ← خروجی بکاپ (JSON)** یک نسخه پشتیبان بگیرید، نسخهٔ قبلی را حذف کنید و سپس نسخهٔ جدید (بیلد خودکار GitHub Actions) را نصب و بک‌آپ را وارد کنید.

## بیلد و توسعه (Build & CI)

این مخزن به‌صورت خودکار از طریق **GitHub Actions** (`.github/workflows/release-apk.yml`) مدیا را در ۴ شارد موازی با Real-ESRGAN بازسازی، تست‌ها را اجرا و APK امضاشده را در بخش Releases منتشر می‌کند.

برای بیلد دستی روی سیستم شخصی:

```bash
# ۱. دریافت مدیای خام (خودکار از exercises-data.js)
DEST=/tmp/exmedia ./tools/fetch_gym_media.sh

# ۲. ارتقای کیفیت با Real-ESRGAN ONNX (یا --fallback-ffmpeg بدون نیاز به پکیج ONNX)
pip install onnxruntime pillow numpy
SRC=/tmp/exmedia OUT=frontend/public python3 tools/convert_gym_media_v4.py

# ۳. تست، بیلد موبایل و سینک با اندروید
cd frontend
npm ci
npm test
node scripts/check-locales.mjs
VITE_MOBILE=1 npx vite build && npx cap sync android

# ۴. ساخت APK (پس از تنظیم android/keystore.properties)
cd android && ./gradlew assembleRelease
```
